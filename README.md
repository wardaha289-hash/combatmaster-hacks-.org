# combatmasterhacks.org

Combat Master Hacks marketing site — Astro 7, static deploy via Cloudflare Workers (`wrangler.toml`).

- **Domain:** https://combatmasterhacks.org
- **Dev:** `npm install` then `npm run dev`
- **Build:** `npm run build`

Brand, SEO meta, checkout URLs, and copy live in `src/config/` and `src/i18n/en.ts`.
